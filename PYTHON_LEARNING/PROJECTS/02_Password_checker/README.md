# Password Checker

Asks for a password and checks it against four rules. If any rule is broken, it lists every problem and asks again, until the password is accepted. 

## Rules

- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit

## How to run
    python password_checker.py
